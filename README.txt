ChatKahani (Android) - on-device AI

1. Android Studio (Koala ya naya) me "Open" karke ye folder kholo. Gradle sync hone do.
2. Phone me USB debugging on karo, phone jodo, Run dabao. (Ya Build > Build APK)
3. Model: Hugging Face (litert-community) se ek MediaPipe .task model download karo,
   jaise Gemma3-1B-IT int4 (.task, ~550MB). App me "AI model chuno" dabao aur wo file chuno.
4. Uske baad chat bina internet ke phone me hi chalegi.
